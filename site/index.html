Quick start

About two minutes from download to http://localhost/.

  1. Download the zip from the releases page. Before unzipping: right-click › Properties › Unblock.
  2. Unzip to a folder with only English letters in its path, for example D:\Stackyard.
  3. Run Stackyard.exe. If SmartScreen warns you: More info › Run anyway.
  4. Start all and open http://localhost/. Your projects go in www\.

MySQL: user root, no password, port 3306. PostgreSQL: user postgres, no password, port 5432.

FAQ

 

Is it really free?

Yes. Stackyard is open source under the MIT License, with no paid tier and no nagging. If it saves you time, you can buy me a coffee.

I'm coming from Laragon. How do I move?

Quit Laragon (or change Stackyard's ports in Settings), copy your projects into www\ or add virtual hosts pointing at their current folders. project.test becomes project.localhost. A MySQL 8.4 data folder can be copied over as is; the README in the zip has the steps.

Why does Windows warn me when I start it?

The exe is not code-signed yet, so SmartScreen does not know it. Click More info › Run anyway. The source code is on GitHub and every release has a SHA-256 checksum.

Why .localhost and not .test?

Browsers resolve *.localhost to your own computer on their own, so Stackyard never has to edit the hosts file or ask for administrator rights.

Can I use other versions of PHP, MySQL or Node.js?

Yes. Unzip any official build into bin\<tool>\<version>\ and press Refresh. PHP, Node.js and Composer can also be downloaded from the app.

Does it change anything outside its folder?

Only what you switch on: entries in your user PATH (a backup is kept before every change) and the "start with Windows" entry. To uninstall, switch those off and delete the folder.
