

THIS IS THE LITE DOWNLOAD: no MySQL and no PostgreSQL (everything else, Adminer included, is here).
To add a database later, unzip it into bin\ and press Refresh in the window:
- MySQL: the "Windows (x86, 64-bit), ZIP Archive" from https://dev.mysql.com/downloads/mysql/
  (8.4 LTS), so that you get bin\mysql\mysql-8.4.x-winx64\bin\mysqld.exe.
- PostgreSQL: the zip from https://www.enterprisedb.com/download-postgresql-binaries. It unpacks
  to a "pgsql" folder; rename it so that you get bin\postgresql\postgresql-18.x\bin\postgres.exe.
Or get the full zip, which has both.
